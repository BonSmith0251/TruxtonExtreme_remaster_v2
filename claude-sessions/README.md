# Claude Code sessions for this project

Snapshot (2026-11-03) of the Claude Code sessions run in `D:\games\Truxton Extreme`, plus the memory notes
Claude kept for the project (`memory/`, with `MEMORY.md` as the index).

- `<session-id>.jsonl.gz` is the session transcript (one JSON event per line). `gunzip` it to read or to resume it
  by copying it back to `~/.claude/projects/D--games-Truxton-Extreme/<session-id>.jsonl`.
- `<session-id>.files.tar.gz` holds that session's side files (`subagents/`, `tool-results/`, the session title).

The transcripts contain the user's prompts, tool output and file paths. Keep the repository private.
